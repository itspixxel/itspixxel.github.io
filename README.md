# Sarthak Sachdeva · Portfolio

This is the source for my portfolio: **[itspixxel.github.io](https://itspixxel.github.io)**

I'm a technical artist and gameplay programmer, working on real-time VFX, procedural animation, and tools for artists in Unreal Engine 5 and Roblox. I'm currently building heroes for Superhero Arena at AriseMedia.

## What's on the site

- **[Superhero Arena](https://itspixxel.github.io/projects/superhero-arena/):** procedural animation, ability VFX and performance work on a live Roblox game
- **[Neptune](https://itspixxel.github.io/projects/neptune/):** an ocean, buoyancy and water system in Unreal Engine 5
- **[Winternator](https://itspixxel.github.io/projects/winternator/):** an Unreal editor tool that generates snow and icicles
- **[ADAPTIK](https://itspixxel.github.io/projects/adaptik/):** terrain-adaptive foot placement for a quadruped in Control Rig

There's more in the [full archive](https://itspixxel.github.io/projects/) and in my [field notes](https://itspixxel.github.io/blog/).

## Running it locally

The site is built with [Astro](https://astro.build) and hosted on GitHub Pages. You'll need Node 22.22 or newer.

```sh
npm ci
npm run dev
```
