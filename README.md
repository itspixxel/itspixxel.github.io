# Game Developer Portfolio Website

A modern, responsive portfolio website showcasing my game development projects, skills, and experience. Built with HTML, CSS, and JavaScript, featuring a clean and professional design with smooth animations and interactive elements.

## Features

- 🎮 **Project Showcase**: Detailed presentations of game development projects including:
  - Ember's Edge (Puzzle Platformer)
  - HellShot (Boomer Shooter)
  - Toxic Shard (VFX System)
  - Winternator (Procedural Tool)
  - And more...

- 🎨 **Modern Design**:
  - Responsive layout that works on all devices
  - Smooth animations and transitions
  - Interactive project cards with hover effects
  - Dynamic background with animated orbs
  - Clean and professional typography

- 📱 **User Experience**:
  - Modal-based project details
  - Smooth scrolling navigation
  - Mobile-friendly design
  - Fast loading times
  - Accessible interface

## Technologies Used

- HTML5
- CSS3 (with modern features like CSS Grid and Flexbox)
- JavaScript (Vanilla)
- SVG for icons and graphics
- YouTube Embed API for project videos
