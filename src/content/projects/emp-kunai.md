### Project Overview

The EMP Kunai is a stylized gameplay VFX system designed for a third-person action character. Built in Unreal Engine 5, it showcases a throwable energy kunai that detonates with an area-of-effect EMP pulse, visually disabling nearby tech and enemies.  
This system was created as part of an ongoing goal to build portfolio projects that solve real gameplay and visual communication problems rather than just isolated effects.

### The Problem

"How can I visually communicate a stylized EMP effect that clearly indicates damage, area of effect, and tech disruption while maintaining a cohesive animation and VFX flow?"

#### Key challenges:

- Making the effect readable in gameplay
- Syncing animation timing with VFX
- Creating clear enemy/tech state changes post-EMP
- Designing a system that’s reusable and optimized

### What I Built

- Projectile FX: Trail, throw arc, and charging core
- EMP Detonation: Expanding shockwave, distortion, dynamic electric arcs
- Target Reaction FX:
  - Enemies: Sparks, flickers, smoke, and particles
  - Tech: Camera shakes, Stunned state in area of effect
- Blueprint interface for easy integration

### Animation & Visual Principles Applied

- Anticipation and slow-in/out on projectile throw
- Arcs and follow-through on energy trails
- Appeal and timing to signal enemy state changes
- Layered VFX elements to support clarity in a stylized world

### Outcome

#### This project demonstrates how stylized gameplay VFX can be:

- Visually compelling
- Functionally readable
- Technically modular
- Rooted in animation principles

It also serves as a prototype for ability design workflows in stylized action games.

### Tools & Technologies

- Unreal Engine 5 Niagara for particle systems
- Blender for character modelling, rigging, and animating
- Substance Designer and Photoshop for texture creation
