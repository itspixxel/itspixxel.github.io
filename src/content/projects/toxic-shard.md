### Project Overview

Created for 'Explosion-tober' 2024, Toxic Shard is a sophisticated VFX system with a projectile and explosion effect. The system features a projectile that would be used as a magic spell or weapon. When it hits a surface, it creates a toxic explosion effect.

### The Problem

"How can a stylized VFX system deliver visually striking toxic explosion effects, while maintaining real-time performance and flexibility for different gameplay scenarios?"

#### Key challenges:

- Creating stylized yet intriguing toxic material behavior
- Optimizing particle count and system complexity
- Balancing visual impact with performance

### What I Built

- Advanced particle system using Niagara with stylized toxic material behavior and physics
- Optimized for real-time performance with LOD system and particle culling
- Customizable parameters for different effects including size, intensity, and spread
- Preset system for quick effect deployment

### Technical & Visual Principles Applied

- Complex particle simulation in Niagara
- Performance optimization techniques including GPU-based particle simulation
- Custom shader system for toxic material visualization
- Blueprint interface for easy integration

### Outcome

- Delivered a visually striking toxic explosion effect for gameplay and cinematic use
- Maintained real-time performance across platforms
- Enabled quick customization and deployment for different scenarios
- Provided technical documentation and peer feedback

### Tools & Technologies

- Unreal Engine 5 Niagara for particle systems
- Blender for mesh creation
- Substance Designer and Photoshop for texture creation
