### Project Overview

Radiant Pulse is a stylized gameplay VFX system for Unreal Engine 5, designed to deliver a visually striking area-of-effect pulse attack. The system features dynamic energy waves, color shifting, and interactive feedback for both players and environment. Built as a portfolio piece, it demonstrates advanced VFX principles and real-time optimization for gameplay clarity.

### The Problem

"How can a VFX system communicate a powerful pulse attack that is readable, visually appealing, and technically optimized for real-time gameplay?"

#### Key challenges:

- Ensuring effect readability in fast-paced gameplay
- Syncing animation timing with player actions
- Creating interactive feedback for environment and targets
- Optimizing for performance and scalability

### What I Built

- Dynamic pulse wave with color shifting and energy distortion
- Interactive hit reaction FX for affected targets
- Customizable parameters for pulse size, speed, and color
- Blueprint interface for easy integration
- Optimized Niagara particle systems for real-time performance

### Technical & Visual Principles Applied

- Layered VFX elements for clarity and visual appeal
- Procedural animation for energy distortion and color shifts
- Performance optimization for consistent framerates
- Modular design for easy expansion and customization

### Outcome

- Delivered a visually compelling and technically robust VFX system
- Enabled designers to easily customize pulse effects
- Improved gameplay clarity and feedback
- Provided technical documentation for integration

### Tools & Technologies

- Unreal Engine 5 Niagara for particle systems
- Blueprints for system integration
- Photoshop/Substance Designer for textures
- Git for version control
