Ember's Edge

Unreal Engine Platformer

About the Project

Ember's Edge is a challenging puzzle platformer set in the depths of hell, where players take control of a nimble character navigating through treacherous environments. The game combines fluid movement mechanics with environmental puzzles, creating a unique blend of action and problem-solving. Inspired by modern platformers and classic puzzle games, it offers a fresh take on the genre with its hell-themed setting and innovative movement system.

Key Features

  • Dynamic movement system featuring wall-running, air dashing, and momentum-based platforming with precise control
  • Environmental puzzles that require both quick reflexes and strategic thinking, with multiple solution paths
  • Unique hell-inspired art style with dynamic lighting and particle effects that react to player actions
  • Progressive difficulty curve introducing new mechanics and challenges at a carefully paced rate
  • Multiple paths through levels encouraging exploration and replayability with hidden secrets
  • Responsive controls designed for precise platforming with customizable input settings
  • Dynamic sound design that enhances the hellish atmosphere
  • Checkpoint system that balances challenge with accessibility

Technical Highlights

  • Custom character controller built in Unreal Engine with advanced movement mechanics including variable jump heights and air control
  • Advanced particle systems for environmental effects and visual feedback with dynamic color and intensity based on gameplay state
  • Efficient physics-based interactions for dynamic gameplay elements with custom collision responses
  • Custom shader system for hell-themed visual effects including dynamic lava flows and corruption effects
  • Procedural animation system for smooth character movement transitions
  • Performance optimization techniques for consistent 60 FPS across platforms

Development Process

The project was developed over 8 weeks, focusing on creating a tight and responsive movement system while maintaining challenging but fair gameplay. The development process involved extensive playtesting to ensure the perfect balance between difficulty and enjoyment.

Development Timeline

  • Week 1-2: Core movement mechanics and character controller development
  • Week 3-4: Level design and puzzle mechanics implementation
  • Week 5-6: Visual effects, shaders, and environment art
  • Week 7: Polish, optimization, and bug fixing
  • Week 8: Final playtesting and refinement

Key Challenges

  • Creating a fluid movement system that felt both responsive and satisfying
  • Balancing puzzle difficulty with player progression
  • Optimizing particle effects and shaders for consistent performance
  • Designing levels that taught mechanics naturally without explicit tutorials

Development Methodology

  • Rapid prototyping of movement mechanics using Unreal Engine's Blueprint system
  • Iterative level design with constant playtesting feedback
  • Modular shader system for easy visual effect customization
  • Performance profiling and optimization throughout development

Tools & Technologies

  • Unreal Engine 5 for core development
  • Blender for custom asset creation
  • Git for version control and collaboration
  • Visual Studio for C++ development

Radiant Pulse

Unreal Engine Niagara VFX

About the Project

Radiant Pulse is a sophisticated VFX system that creates a dramatic energy beam effect inspired by iconic anime moments. The system consists of three intricately designed components: an energy gathering orb, a powerful energy beam, and dynamic ground dust effects. The effect is carefully timed across 7 seconds, with 2.5 seconds dedicated to energy gathering and 4.5 seconds for the beam and ground effects, creating a cinematic and impactful visual experience.

Key Features

  • Multi-stage VFX sequence with precise timing control for each phase
  • Dynamic particle systems for energy orb formation with customizable intensity
  • Beam collision effects with environment including reflection and refraction
  • Impact particle effects with realistic physics-based behavior
  • Customizable color and intensity parameters

Technical Highlights

  • Complex Niagara particle systems with custom physics calculations
  • Timeline-driven effect sequencing with precise control
  • Dynamic material parameters for real-time effect customization
  • Advanced lighting system for energy beam visualization
  • Custom shader system for energy effects

  • Blueprint interface for easy integration

Development Process
